# Mitwirken

Kleine, nachvollziehbare Änderungen mit einem reproduzierbaren Beispiel einreichen.
Für neue Regeln Datenquelle, fachliche Grenze und erwarteten Nachtest dokumentieren.
Tests: `python3 -B -m unittest discover -s tests -v`.
Keine echten Kundenberichte oder Secrets, keine versteckten Dienste und keine
kostenpflichtigen Fallbacks. Umgebungsintegration getrennt vom Prüfkern testen.
