# Akquise-Briefing

Der Assistent soll nicht alle Fragen auf einmal stellen. Bis zu drei zusammengehörige
Themen pro Runde, vorhandene Antworten übernehmen und konkrete Auswahlhilfen anbieten.

| Block | Zu klärende Angaben |
|---|---|
| Angebot und Zweck | Leistung, Kundennutzen, eigene Website, Vertriebs-/Partnerschaftsziel |
| Zielunternehmen | Branche, Geschäftsmodell, Größenmerkmale, Technologien, Sprache |
| Suchgebiet | Länder, Region/Stadt, Firmensitz oder Niederlassung, belegbarer Umkreis |
| Auswahl | Muss-/Wunschkriterien, Konkurrenz, Bestandskunden und Ausschlüsse |
| Umfang | gewünschte eindeutige Firmenzahl, Zeitlimit, Kostenbudget |
| Informationen | gewünschte Spalten, Reihenfolge, Kontakte, Quellen je Feld |
| Ausgabe | Excel/LibreOffice/CRM, Trennzeichen, Kodierung und Ablage |
| Datenumgang | Personenbezug, Zugriff, Aufbewahrung, Aktualisierung und Löschung |

Vor breiter Recherche müssen Angebot, Zielkundentyp, Gebiet und Umfang hinreichend
klar sein. Sachentscheidende Lücken nicht selbst erfinden. Unkritische Defaults
benennen: Semikolon, UTF-8-BOM, keine Kosten und keine Kontaktaufnahme.

Das Arbeitsprofil ist eine kurze Zusammenfassung, keine zweite lange Befragung.
Wunschdaten dürfen frei ergänzt werden. Wenn Personenangaben wirklich erforderlich
sind, passenden Rahmen klären; allgemeine Geschäftskontakte bevorzugen.

Der vollständige Fragenvorrat liegt unter `Akquise-Skill/references/briefing.md`.
