# Integrationen und Kosten

Keines der folgenden externen Werkzeuge ist eine Pflichtabhängigkeit des aktuellen
Python-Kerns. Vor tatsächlicher Integration Version, Lizenz, Rechte und Kosten prüfen.

| Werkzeug | Geplanter Einsatz | Stand |
|---|---|---|
| Scrapling | gerenderte Seiten und Extraktion | optional, noch kein eingebauter Adapter |
| Lighthouse | lokale Labormessung | geplant |
| Playwright MCP | gezielte Browserbedienung | vorhandenes Werkzeug bevorzugen |
| Search Console | eigene Suchleistungsdaten | Dateiimport/API geplant |
| CrUX/PageSpeed | Feld-/Labordaten | geplant, Quelle/Aggregation trennen |
| Ahrefs | externe SEO-Daten | optional kostenpflichtig; alten lokalen MCP vermeiden |
| DataForSEO/OpenSEO | SERP-/Keyword-Daten | optional mit Verbrauchskosten |

Die Akquise-Recherche nutzt verfügbare Such-/Browserwerkzeuge. Keine neue Quelle
anschließen oder kostenpflichtige Abfrage auslösen, nur weil ein Briefing existiert.
Ein Werkzeugausfall darf keine geschätzten Messwerte als Ersatz erzeugen.

OAuth/Tokens pro Nutzer/Projekt und kleinste Rechte. Zugangsdaten nicht in Git,
Prompt, Wiki oder CSV. Lokales Skill-Repo registriert keine Cloud-Verbindung.
Kostenloser Quellcode bedeutet nicht kostenlose KI-Nutzung, APIs oder Hosting.

Recherchequellen und Anbieterlinks stehen in [Lizenz und Quellen](Lizenz-und-Quellen.md).
