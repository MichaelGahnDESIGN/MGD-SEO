# Glossar

| Begriff | Bedeutung |
|---|---|
| Befund | dokumentierte Beobachtung mit Nachweis und Empfehlung |
| Canonical | Hinweis auf eine bevorzugte URL-Version |
| Crawl | begrenztes automatisches Abrufen von Seiten |
| DOM | vom Browser aufgebaute Seitenstruktur, gegebenenfalls nach JavaScript |
| Field-/Felddaten | Messwerte echter Nutzung, etwa aus CrUX |
| JSON-LD | strukturiertes JSON-Datenformat in Webseiten |
| Labordaten | Messung in einer definierten Testumgebung |
| Lead/Kandidat | potenziell passende Firma; kein Nachweis von Kaufinteresse |
| MCP | Anschlussstandard für Werkzeuge von KI-Anwendungen |
| noindex | Anweisung, eine Seite nicht in den Suchindex aufzunehmen |
| Origin/Ursprung | Kombination aus Protokoll, Host und Port |
| robots.txt | Regeln für automatisierte Seitenabrufe, keine Zugangssicherung |
| Skill | Anweisungen und passende Hilfsmittel für einen Agenten |
| CSV | Tabellenformat aus Text mit definiertem Trennzeichen |
| BOM | Kodierungsmarkierung, die Excel bei UTF-8 helfen kann |
| Formel-Injection | fremder Zellinhalt wird beim Tabellenimport als Formel interpretiert |
| Kontaktfreigabe | gesondert geprüfte Erlaubnis für eine konkrete Kontaktaufnahme |
